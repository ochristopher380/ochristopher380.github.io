Canvas Planning Tool
An interactive map with filters and a tooltip to help candidates with limited resources focus their canvassing efforts to where the votes are.
Project Details
Candidates running for office have limited resources and volunteers, this is especially true for local races such as school board. In order for candidates to focus their efforts, they need to know who might vote in the next election. Precincts offer the most granular level of understanding where voters reside. I pulled election resuls from the county clerk's website and precinct shapefiles to create an initial map in Folium. The final dashboard was created with Shiny for Python with ipyleaflet used to create the map. I refactored the initial map from Folium to ipyleaflet in order to utilize the the efficient updates of jupyter widgets in the Shiny framework allowing more efficient updates to be made to the map by the user.
