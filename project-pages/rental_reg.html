Seattle Rental Registration Archive
Using publicly available data to understand changes in Seattle's rental market
Project Details
The City of Seattle requires all rental properties in the city to register with them as rental properties and this registration data is available through the City’s open data portal. What you will find however is that this data set does not include any historical data, it is only a present-moment snapshot and the city does not store this historical data.
Why throw this valuable data away?! During my master's program, I lead a class group project to archive this data and I have rewritten the code for that project to run the project in the cloud!
Each day the City’s data set is checked to see what new registrations have been added and which are no longer registered. I store this data in a database and you can access the historic dataset through an API I have written with Flask. By making a get request to http://cnolson.pythonanywhere.com/SeattleRentalRegistrations, you will get the data from the current registration data set as well as data historical data captured since October, additional latitude and longitude data from geocoding I have added, additional historical data I scraped from the registration urls using scrapy-playwright and code complaints and violations for the property from the City’s code complaints dataset.
This project is still ongoing. I hope to add additional API endpoints, add more data, improve data quality, and create an interactive dashboard with the data in the future.
